# User Instructions & Project Rules

- **Scope Discipline (CRITICAL):** When the user requests a change or addition to a specific function or feature, ONLY modify the code related to that specific requested feature.
- **Do NOT** modify, delete, or refactor any other functions, features, or files without explicit permission from the user.
- **Do NOT** rewrite entire files unless necessary for the specific function being worked on. Use targeted edits.
- Treat existing code as stable and off-limits unless it directly intersects with the current task.
- **No Unsolicited Code Changes (CRITICAL):** When the user asks a question, ONLY answer it. ALWAYS assume "Answer Only" mode. Do NOT change any code or system file without explicit permission from the user.
- **Remember Context:** Always remember the current context and the specific feature/file the user is actively working on across conversations.
- **Explain Before Acting:** Before making any code changes for a request, briefly explain what changes will be made and their effects. Wait for explicit permission before applying them.
